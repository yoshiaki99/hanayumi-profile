# はなゆみLP制作サービス・代表の自己紹介

公式LINEから案内する、徳永佳明の自己紹介ページです。原稿と顔写真をもとに制作し、はなゆみの公式ロゴを使用しています。ピンクはロゴだけに使用し、本文は白地・紺色のアクセントで統一しています。スマートフォンで順にスクロールして読むための1カラム構成です。

公開URL: https://yoshiaki99.github.io/hanayumi-profile/

## 構成

- `index.html`: 自己紹介本文（ヘッダー・フッター・ナビゲーション・ホームページへのリンクなし）
- `style.css`: PC・スマートフォンに対応するレイアウト
- `assets/`: ページの表示に使用する顔写真・公式ロゴ
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信する設定

ビルド不要です。`main` ブランチのルートからGitHub Pagesで公開します。原稿ファイルと元の写真ファイルはリポジトリに含めていません。

フォントはGoogle FontsのNoto Sans JPを使用し、読み込めない場合はOSの日本語フォントで表示します。

## ローカルプレビュー

このフォルダで `python3 -m http.server 8973 --bind 127.0.0.1` を起動し、http://127.0.0.1:8973/ を開きます。
